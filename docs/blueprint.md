# **App Name**: Readingmath HQ Admin

## Core Features:

- Admin Dashboard: {관리자계정}님 로그인하셨습니다. 영역 노출
- Institution Management: 기관 정보, 학생 목록, 강사 목록, 포인트 내역, 결제 내역, 문의 내역, 활동 로그 관리
- Student Management: 학생 정보, 학습 내역, 주간 학습 알림, 학습 보고서, 진단 평가 보고서, 결제 내역 (B2C) 관리
- Teacher Management (B2C): 강사 목록 및 월별 관리 현황 관리, 강사 관리자 페이지 바로 가기 링크 제공
- Content Management: 진단 평가, 학습 콘텐츠 (수학, 과학), 커리큘럼 관리
- Bulletin Board Management: 공지 사항, 자료실, FAQ 관리
- Branch Management: 지사 목록 및 정산 내역 관리
- Settings: 이용 약관 수정, 운영자 관리, 로그 관리

## Style Guidelines:

- 주요 색상: 교육 자료에서 영감을 얻은 다크 블루 (#1A237E). 밝은 요소의 배경으로 적합
- 배경 색상: 채도가 최소화된 매우 밝은 청회색 (#F0F4F8)
- 액센트 색상: CTA에 시선을 사로잡고 대비를 만드는 보라색 (#673AB7)
- 글꼴 조합: 제목 및 짧은 텍스트 블록에는 'Poppins' (sans-serif), 본문 텍스트에는 'PT Sans' (sans-serif)
- 사이드바, 헤더 및 콘텐츠 영역으로 구성된 3 섹션 레이아웃
- 아이콘은 단순하고 현대적이어야 하며 해당 섹션과 관련되어야 함
